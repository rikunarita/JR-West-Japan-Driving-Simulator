## 【キーボードによる操縦】
### 221系以降の世代の車両(221系、225系、323系)
* **マスコン(加速・力行)**：W、Sのキー
* **ブレーキ**　　　　　 ：↑、↓の矢印キー
* **惰性**　　　　　　　 ：マスコン「切」かつブレーキ「ゆるめ」の状態にする。
### 221系より前の世代の車両(205系、201系、103系)
* **マスコン(加速・力行)**：W、Sのキー(103系のみD、A)
* **ブレーキ**　　　　　 ：→、←の矢印キー
* **惰性**　　　　　　　 ：マスコン「切」かつブレーキ「ゆるめ」の状態にする。
### 全車両共通の操作
* **時刻表の表示**：画面の右中央にマウスカーソルをあてるか、Jキー長押し
* **逆転ハンドル**：Ｑ、Ｚキー
* **ＡＴＳ確認**　：ブレーキ１ノッチ以上にしてＭキー
* **指令に連絡**　：画面左にマウスカーソルをあてて、ボタンをクリック
* **ＡＴＳ復帰**　：画面上部中央にマウスカーソルあてて、赤いボタンをクリック
* **ＥＢ装置リセット**：Vキー(マスコン・ブレーキ操作でも可)
* **ＥＢ装置復帰**：指令から運転再開の許可をとってからVキー
* **警笛**：スペースキー
* **非常ブレーキ**：Enterキー
#### 225系と323系のミュージックホーンの操作
* Xキー
### その他の操作
* **前照灯**：Bキー(減光/解除)、Nキー(ON/OFF)
* **警報・ブザー音量**：マスコンハンドルの上の白いバーをクリックで動かす。
* **ドア(ワンマン時)**：0キー(左閉扉)、1キー(左開扉)、6キー(右閉扉)、9キー(右開扉)
### ワンハンドルの設定に切替えた場合の操作
* **逆転ハンドル**：F、B
* **マスコン**　　：↑、↓の矢印キー(←で惰性に切替え)
* **ＡＴＳ確認**　：ブレーキ1ノッチ以上にしてEnterキー
* **ＥＢ装置リセット**：Enterキー(マスコン操作でも可)

### ポーズ画面の操作
* **ポーズ画面を表示/解除**：乗務中、Ｐキー
* **乗務を中止**　　　　　 ：ポーズ画面表示中、Ｅキー

## 攻略
### 停車駅前のブレーキ操作
* **35km/h** の場合、停止位置の**80m手前からB4**。
* **80km/h** の場合、停止位置の**300m手前からB5**。
* **130km/h** の場合、停止位置の**800m手前からB5**。

### ホームがかり(駅進入速度)
* **大和路線**：50km/h
* **神戸線**：60km/h

### 非常ブレーキの制動距離
* 100km/hから非常ブレーキを使用した場合、**400m先に**停止。

### 103系と201系のブレーキ操縦
* **直通ブレーキ**：ハンドルの角度に比例してブレーキが掛かります。（推奨）
* **自動空気ブレーキ**：ゆるめ位置、重なり帯、減圧帯、非常帯にハンドルを合わせてブレーキ力を調整します。（高難易度化）
* 直通ブレーキ使用時は、「直　通」の黄色いランプが付きます。
* 運転開始時のブレーキ弁ハンドルの位置が、直通ブレーキにおける最も強いブレーキ力になります。
* そこから右側は、自動空気ブレーキの重なり帯、減圧帯、非常帯の順になります。ブレーキ弁ハンドルを重なり帯に合わせるとブレーキ力を保持し、減圧帯に合わせるとブレーキ力を強くします。非常帯は非常ブレーキです。
* ゆるめ位置に合わせると、ブレーキ力を弱めます。合わせっぱなしはブレーキ力がなくなるので、停車ブレーキ時は気を付けます。
* 自動空気ブレーキ使用時はキー操作を推奨します。ゆるめ位置はK、重なり帯はL、減圧帯はO、非常帯はEnterで合わせます。←(ここでは、このような操作のことを三方弁での操作と呼ぶことにします。)
* ブレーキ使用時は、ブレーキシリンダー圧力(BC圧)計の黒い針を確認することを推奨します。
* 103系や201系を選択して、国鉄型のブレーキの操縦を体験してみてください。
